# Mermaid VTuber Website — Design

## 1. Design Concept

### Theme

Mermaid VTuber dengan nuansa **magical underwater fantasy**.

Website terasa seperti pengunjung sedang menyelam ke dunia bawah laut sang streamer.

### Visual Direction

* Underwater fantasy
* Dreamy
* Magical
* Elegant
* Slightly mysterious
* Modern VTuber aesthetic

### Main Character

* Mermaid
* Toska / turquoise hair
* Mermaid tail
* Ocean-inspired accessories
* Soft magical glow

---

# 2. Color Palette

## Primary

* Deep Ocean Blue
* Teal
* Turquoise

## Secondary

* Cyan
* Pearl White
* Soft Lavender

## Accent

* Coral Pink
* Seafoam Green
* Pearl / Gold accents

## Background

* Dark underwater gradient
* Deep blue → teal
* Subtle light rays from the ocean surface

---

# 3. Typography

## Heading

Elegant fantasy / slightly magical typeface.

Used for:

* Section titles
* Character name
* Important statements

## Body

Clean modern sans-serif.

Used for:

* Descriptions
* Navigation
* Schedule
* Content metadata
* Buttons

---

# 4. Global UI Style

### Cards

* Rounded corners
* Semi-transparent backgrounds
* Glassmorphism
* Subtle blur
* Thin borders
* Soft glow

### Buttons

* Rounded / pill shaped
* Turquoise or cyan accent
* Soft hover glow
* Clear CTA

### Decorative Elements

* Bubbles
* Pearls
* Shells
* Coral
* Seaweed
* Jellyfish
* Small fish
* Ocean particles
* Light rays

### Animation

Keep animations subtle.

Examples:

* Floating bubbles
* Slowly moving particles
* Gentle underwater movement
* Character hair movement
* Soft glowing elements
* Parallax background
* Wave movement

---

# 5. Navigation

```text
[LOGO / CHARACTER NAME]

HOME
ABOUT
CONTENT
SCHEDULE
LORE

                    [SOCIALS]
```

Navigation should be minimal and transparent.

On scroll:

* Background becomes slightly darker
* Glassmorphism effect appears
* Navigation remains fixed

# 14. Responsive Design

## Desktop

* Large character artwork
* Full underwater environment
* Horizontal navigation
* Multi-column content cards

## Tablet

* Reduced artwork size
* 2-column content
* Simplified navigation

## Mobile

* Mobile navigation
* Single-column content
* Character remains the primary visual
* Horizontal scrolling for content cards
* Reduced decorative effects

---

# 15. Dynamic Data

The website should automatically retrieve content where possible.

### Dynamic

* Live / Offline status
* Current stream
* Latest YouTube videos
* YouTube Shorts
* Instagram content
* Upcoming streams
* Stream thumbnails
* Stream title

### Static

* Character profile
* Lore
* Biography
* Likes / Dislikes
* Social links
* Website theme
* Character artwork

The website should **not require uploading content manually**.

Content remains hosted on the original platforms, while this website acts as the central hub.

---

# 16. Overall Experience

The website should feel like:

> **"You are diving into the world of a mermaid who happens to be a streamer."**

Rather than:

> "A streamer website with an ocean theme."

The ocean environment should therefore be part of the **experience and navigation**, not just decoration.
